# 填列说明（spec）格式

一个 JSON 文件放一个对象或一个对象数组。每个对象对应结果表的一行（一个组合）；同一行的所有内容放在同一个对象里。

```json
{
  "result_row": 123,
  "label": "写入结果表 Q 列的口径标记（必填）",
  "source": "追加到底稿汇总行 AC 列的来源说明（必填）",
  "note": "追加到底稿汇总行 U 列的备注（可选，默认用 label）",

  "guarantee":  { "cash_value": [], "survival": [], "maturity": [], "terminal": 40 },
  "accumulate": { "dividends": [], "balance": [], "mode": "series" },
  "paidup":     { "total_cv": [], "extra_annuity": [], "extra_maturity": [], "mode": "series" }
}
```

所有数组**从第 1 个保单年度末开始**，一个元素一年，单位元，对应 10 万元保费口径。

## guarantee（新增保证利益逐年块）

只用于还没有逐年块、保证三项均为待补的组合。

| 字段 | 含义 |
|---|---|
| `cash_value` | 各年末保证现金价值（年金为当年给付后）。必填，不允许 `null`，长度 = 保障到期的保单年度数 |
| `survival` | 各年末保证生存金/年金。可省略（视为 0） |
| `maturity` | 各年末保证满期金。可省略 |
| `terminal` | IRR 终点年度。省略时：年度数 ≥ 40 取 40，否则取最后一年 |

## accumulate（累积生息）

| 字段 | 含义 |
|---|---|
| `dividends` | 各年当年红利。给了它，余额由脚本按底稿的累积利率累积 |
| `balance` | 各年末累积红利余额。未披露年度写 `null`。与 `dividends` 同时给出时用于核对（相差须小于 1 元） |
| `mode` | `series`（默认）：写入逐年数据和公式。`constants`：只把结论写成数值，不写逐年数据 |

规则：IRR 终点年度必须有数；返本/翻倍只有在该年度之前每年都有数时才填，否则保持待补并列入报告的 `undetermined`。底稿 P 列已有的数（此前录入的官方披露点）保留不变，新数据在这些年度与它们相差超过容差（`--tol`，默认 1 元）时整组拒绝。

## paidup（交清增额）

| 字段 | 含义 |
|---|---|
| `total_cv` | 各年末含交清增额的总现金价值。必填，未披露年度写 `null` |
| `extra_annuity` | 各年红利年金（仅年金产品）。可省略 |
| `extra_maturity` | 各年红利满期金（通常只有满期年度非 0）。可省略 |
| `mode` | 同上 |

规则：总现金价值不得低于保证现金价值；寿险不接受 `extra_annuity`。

## 什么时候用 `mode: constants`

只在一种情况下用：结论不是由一列完整的逐年数据直接得出，而是经过换算或证明（例如官方披露点稀疏，用另一来源的逐年数据确定年度落点）。此时：

- 脚本用你提供的数组算出结论，把结论作为数值写进汇总行，不动逐年块里已有的官方数据；
- 标注必须写明这是“换算判定”或“推算值”以及方法；
- 已填指标不要求与新数据一致（因为两者口径本来不同），所以更要在标注里说明口径差异。

## 标注模板

标注写给看表的人，一句话说清数的性质。常用写法（把【】换成实际内容）：

官方资料：

```
【日期】填列：累积生息—【公司】《【产品说明书名称】》第【页】页利益演示表（演示利率【3.5%】，40岁男性，【5年交】，年交保费【10万元】），披露年度【1—10、15、20…】；返本、翻倍年度之前各年均有披露。
```

平台数据，已按比值认定：

```
【日期】填列：累积生息—平台公开预览演示逐年数据；当年红利÷上年末保证现价交费期满后为1.225%，与该演示利率对应的1.225%一致，按比值认定。
```

平台数据，未能认定为目标口径（使用人同意照原样填）：

```
【日期】按使用人要求补填：累积生息—取自平台公开预览演示逐年数据，按平台原样填列；当年红利÷上年末保证现价交费期满后为【0.98%—1.05%（中位1.02%）】，不是目标演示利率对应的1.225%，未能认定为目标口径。
```

折算、推算：

```
…；平台按另一基本保额列示全部利益，已乘以恒定系数【4.445235】（底稿保证现价÷平台保证现价，各年度恒定）折算，属折算值。
…；翻倍年度落在官方未披露年度之间，按【方法】判定，属换算判定。
```

仍缺的部分也写进同一条标注：`交清增额仍无数据：【原因】`。

来源（AC 列）写法：

```
【日期】补填来源：【文件名或平台条目】【网址】；参数：40岁男性，年交保费100000元，【5年交】，【红利中档】；【取数方式】；原始文件归档【相对路径】。
```
